Register-Rooted Unate Synthesis
for DOMINO and CMOS

Bounded functional decomposition, shared-cost optimization and selection across CMOS network topologies

Shared synthesis flow and options · ABC synthesis

1Motivation and Contribution

A DOMINO gate [1] evaluates a function that is monotone in its supplied rails through a series-parallel pull-down network; a DOMINO latch additionally holds the value as the cycle's state. Absorbing a register's next-state logic into one or two such stages creates an opportunity that ordinary combinational covering does not explicitly target. Output-phase assignment and DOMINO mapping [2, 3], and earlier unate decomposition [12, 13], provide the foundations. Here the synthesis objective is the complete mixed static/DOMINO implementation of each next-state cone, including the logic it shares with other consumers.

The method combines three decisions: where to place an endpoint's functional boundary, how to realize its exact function under DOMINO constraints, and which shared static logic must remain. Exact bounded truth tables let the search move beyond the XAG's current factoring; divisor-image care sets expose alternative endpoint functions; coordinated endpoint selection captures gains unavailable to independent choices. Residual optimization feeds changed interfaces back into selection. Literal-network extraction further explores using stable controls to simplify the function evaluated in the dynamic phase (Section 6). These contributions concern the organization and target objective of the search; cut enumeration, unate covers and resubstitution build on established methods.

The method separates a logical mixed static/DOMINO target from a static CMOS realization. Freezing preserves the selected endpoint functions, phases and source-state correspondence; CMOS expansion realizes those functions with static logic and the original registers. Transistor cost and stage count are logical objectives, while cell covering uses a technology library. Fig. 1 and Table I contrast this organization with the ABC flow. Shared infrastructure is described in synthesis.html (cited as [S §n], and the ABC page as [A §n]); network topology selection is developed in Section 5.

2Regions and the Logical Network

The shared region construction [S §2, §3] uses a flop-to-flop profile to keep each register's next-state cone together. Logical translation preserves every original register bit and pipeline stage independently of library cell selection. Reset, clock and initialization semantics are protected; memories, clock gates, latches and opaque instances remain native barriers. Each region supplies an XAG, a structurally hashed AND/XOR graph with complemented edges. Mux, SOP and decomposition candidates ultimately expand into this common representation; there is no runtime switch to a separate whole-design BDD or majority graph.

The XAG supplies dependencies and reusable signals; a selected boundary supplies the variables of an exact Boolean function. Moving that boundary can hide a complex subfunction behind one input, expose unateness or change which logic the endpoint absorbs. Inside an admitted window, synthesis uses the truth table rather than preserving the original AND/XOR factoring. Functional resubstitution can also use divisor sets that are not structural cuts, provided they determine the endpoint exactly. Structural bias thus remains in bounded window and divisor discovery, but does not constrain the subsequent realization to the original subgraph.

Definition 1 (Endpoint). An endpoint is a bit of a positive-edge register in a known clock domain whose next-state function Fq is computed inside the region. Its cone is the XAG transitive fan-in of Fq up to region inputs and register outputs. Negative-edge and unknown-edge registers are not endpoints; their cones stay static.

Initial topology and light preselection cleanup (P1)

The logical translation seeds the XAG with arithmetic and mux topologies. Prefix carry, carry-save multiplier compression and balanced comparisons expose parallel structure; ripple and array lowerings retain alternative area-oriented seeds. Indexed muxes can use decoded products or binary mux trees. Sparse and aliased arms retain their semantics, and a wide two-arm selector still tests nonzero. Seed selection differs from reconstructing a mux-like function discovered later in a local window.

Light preselection cleanup (P1) uses bounded exact sweep, AND/XOR balancing and positive-gain NPN4 rewriting, without retained choices or resubstitution. Its work is capped and receives only a fraction of the remaining search allowance, reserving work for endpoint selection. P1 can expose a different window or remove a useful divisor, so its admission is judged within a complete synthesis profile (Section 7).

3Register-Rooted Endpoint Selection

Definition 2 (Cells). A DominoLatch computes Fq and stores it as the endpoint's state; a Domino cell is a phase-1 stage that feeds a DominoLatch; a Static cell is ordinary CMOS. A DOMINO formula is legal when it reads at most 8 logical inputs (x and ¬x count once), has a series stack of at most 4 and at most 10 factored parallel branches. The logical cell model supplies both output rails; complementary static inputs require a charged inverter unless already available. A function binate in a logical variable can therefore use both rails in a formula monotone in its rail inputs, without first making the entire network unate by output-phase assignment. This is a Boolean rail model; physical monotonicity and clocking require a characterized implementation.

Selection minimizes a transistor proxy, used consistently by every search and acceptance test:

cost = 2·#AND + 4·#XOR + #NOT (static)  +  Σcells ( |formula| + 5 [Domino] + 8 [DominoLatch] )(1)

where |formula| is the transistor count of the pull-down network and static logic and inverters shared between cells are counted once. Each region starts from an identity baseline: one DominoLatch per endpoint fed by its unchanged static cone, which is always legal. Every endpoint then searches, under its own work slice, for a cheaper realization (Algorithm 1), and keeps the baseline if the search fails or runs out of work.

Exactness boundary. For a fully specified unate function, normalizing its input polarities gives a positive monotone function whose minimal true points determine the unique irredundant monotone SOP cover. This cover is exact; minimizing the transistors of a factored series-parallel network is a separate problem. Factoring, signed covers for binate functions, boundary discovery and decomposition encoding are bounded searches. Every retained formula is checked exactly, but failure to find one does not establish infeasibility or optimality.

Algorithm 1 SELECTENDPOINT(q) — tiers in order, each bounded
  1. incumbent ← identity cell; admit a window: the whole cone or a reconvergence-driven window of ≤ 16 inputs
  2. one cell: the whole window in one DominoLatch; unate ⇒ exact minimal cover, else a bounded signed cover, series-parallel factored
  3. decompose F(B, R) = H(G0(B) … Gk(B), R): new phase-1 divisors Gi as Domino cells
  4. boundaries: enumerate cut frontiers (≤ 32) with contraction and growth moves; existing-divisor two-cell covers; wide-boundary round
  5. two-phase general tier; residual removal with care completion over ≤ 16 phases; witness-guided local divisors
  6. validate the best candidate exactly; commit iff its total cost (1) is lower

Care-aware divisor search. For divisors D(x) on one admitted independent-input basis, a top function exists exactly when D(x) = D(y) implies F(x) = F(y). Its care set is the image of D; unreachable combinations are free to complete. For a chosen input polarity, upward closure of the required true points yields the least monotone completion, or proves that polarity impossible if it reaches a required zero. The search tries bounded polarity and completion alternatives and checks their composition against F. A dependence conflict provides two assignments that a further divisor must separate, guiding search beyond structural cuts. These are local combinational don't-cares, not assumptions about reachable sequential states.

New functional divisors follow Ashenhurst–Curtis decomposition [4]. All functions and compositions are checked over truth tables of up to 16 inputs. Candidate cost includes the endpoint, any first-phase cells, the remaining static cones and demanded inverse rails. An unchanged outside consumer protects its cone from removal credit: absorbing a shared subfunction into one endpoint cannot make its still-needed static implementation disappear.

Coordinated endpoints. If two endpoints share a static cone, changing either alone may add DOMINO cost while leaving that cone live; changing both can remove it and become profitable. Pair and joint reselection therefore compare complete regional cost, including interface alternatives that lose individually. Shared gates reaching exactly two endpoints in one clock domain seed pair trials; joint search can also use shared source inputs. Bounded private fanout-free windows preserve outside readers, while common functional divisors and joint recoding explore shared first-phase implementations. Every affected endpoint must remain legal and exactly equivalent; only a strict total-cost gain commits. The search is procedural and bounded, without a global optimality claim.

4Residual Optimization

Logic not absorbed into cells is a shared multiple-output network: its boundaries include primary outputs, unselected next states, selected-cell inputs and protected control ports. Bounded rewriting [5], resubstitution [6] and balancing preserve these functions and use nonzero AND/XOR costs with depth guards. These are established combinational operators; their role here is to improve the residual network under the same regional objective as endpoint selection.

The region is replaced only if its total cost (1) does not rise. One feedback round then re-selects endpoints whose static inputs changed, because a better residual implementation can expose a different absorption boundary or alter sharing costs. Endpoint and residual synthesis are thus coupled through their interfaces before freezing, rather than treating selected cells as permanently fixed barriers. Native search uses exact bounded Boolean checks without a SAT or SMT solver; independent whole-design LEC remains a separate validation step.

5Freeze, CMOS Expansion and Topology Selection

The selection is frozen into an endpoint netlist of Static, Domino and DominoLatch cells with their functions, formulas, rails, phases and source-state correspondence; identical phase-1 cells in one clock domain are shared, and the whole artifact is validated (functions, legality, shared cost, phase order, clock domains) or nothing is published. It is then expanded into behavioral CMOS: one native register per original bit and stage, each cell's formula as static logic, no phase-1 storage. Expansion is structural and checked exactly against every register's reference next state.

5.1Where topology search runs

There are three distinct placements. P1 cleans the initial static network before endpoint selection (Section 2). P2-R optimizes the residual after selection and can feed changed interfaces back to endpoints (Section 4). P2-C cleans the private, validated CMOS expansion over all outputs and next states, across former DOMINO cell boundaries. Multi-representation choice extraction runs in P2-C, where total-function alternatives can be compared without changing the frozen endpoint model.

The frozen endpoint model remains the logical DOMINO result. P2-C can refactor its expanded static functions, while original state, controls, memory and opaque barriers remain fixed. No endpoint feedback follows P2-C. Native DOMINO cost (1), CMOS ranking proxies and actual mapped PPA therefore describe separate artifacts and objectives.

5.2Alternative network topologies

A topology specifies how a Boolean function is factored into connected operators. The same function may favor a shared AND/XOR DAG, a balanced product/sum structure or a tree of conditional decisions. An admitted window of at most eight independent inputs supplies one exact function, which is re-expressed in bounded alternatives [7–10]. Each valid alternative is hash-consed back into XAG scratch storage. The incumbent always remains available.

5.3Retain choices, then select a complete network

Definition 3 (Structural choice). A choice class owns an incumbent root and equivalent alternative roots on the same ordered independent basis. Candidate ownership keeps an alternative available; selected liveness determines which gates are counted in the emitted network. Keeping three alternatives does not charge three physical implementations.

Each completed candidate must equal the original total function on that basis. Endpoint care completions from Section 3 cannot become global choice equivalences outside their validated context. Candidate admission rejects dependencies on the old root or its transitive fanout. Even locally valid classes can interact through overlapping cones, so final extraction checks cycles and rebuilds a complete DAG with all original sources and output/state ports preserved.

Algorithm 2 Explore representations and select one consistent CMOS topology
  1. keep a complete incumbent snapshot; admit bounded local windows on ordered independent bases
  2. build DSD, positive/negative SOP, BDD and applicable NPN4 candidates in charged scratch storage
  3. validate total equality and dependency legality; price candidates for local cost and depth
  4. retain the incumbent and up to two distinct area/depth alternatives in each admitted class
  5. extract complete area-oriented and depth-oriented selections from the same snapshot
  6. reject cycles; reprice actual selected sharing over all outputs and next states; require no output-depth increase
  7. try at most eight single-class changes to recover sharing missed by local prices
  8. keep a strictly better complete network under the ranking objective; retain the incumbent on a bound or refused trial

A locally cheapest cone can lose globally if it duplicates logic shared with another output. Whole-network repricing counts live shared gates and rails once, and bounded recovery can restore an incumbent class member to recover that sharing. Area/depth extraction reduces structural bias, but the finite candidate set and bounded recovery do not solve global optimal covering. Only the selected XAG is exported as an Lnet; choice classes are resolved before technology mapping.

5.4Ranking objectives and resource bounds

A library-independent objective uses weighted AND/XOR cost and logic depth. A library-aware objective instead derives a bounded legal-cell inventory from the library's Boolean functions and cell areas, estimating combinational cell count or area. Pin/output phases and shared inverse rails enter pricing. These estimates rank native candidates; cell covering and physical timing remain separate stages.

Candidate construction, exact validation, retention and complete-network extraction share finite work and storage allowances. Retained cut counts bound NPN4 exploration; word and node limits bound sweep, SOP and BDD construction; a duplication allowance constrains balancing of shared cones. Cost and output-depth guards decide whether a rebuilt network replaces the incumbent. Mandatory validation and publication retain reserved resources, so optional search exhaustion cannot publish an incomplete network.

6Literal-Network Extraction

In a DOMINO pipeline a register's output is stable during the first half of the cycle, while DOMINO gates evaluate in the second. Logic controlled only by registered signals can therefore settle in the otherwise idle first half and choose the literals a DOMINO gate reads, as precomputation does for power [11]. The transformation runs between expansion and final cleanup; the number n of control variables bounds the cofactor and substitution search.

Definition 4 (Literal network). Let a selected cell compute F(c, r) with n controls c driven by register outputs or primary inputs. Shannon expansion gives F = ∨v [c = v] · Fv(r). A template T(s1…sm) realizes all cofactors if for every v there is a substitution λv mapping each slot to a literal of r, its complement or a constant with Fv = T ∘ λv. The literal network realizes each slot as a balanced tree of 2:1 multiplexers over c (depth n) selecting λv(sj).

The cell then implements T instead of F. The search enumerates bounded control subsets and cofactor-derived templates, using ternary-simulation pruning to find slot substitutions. Every retained rewrite is checked over all admitted input assignments. For the logical DOMINO target, selected cells and their literal networks retain phase and rail constraints while residual static logic is optimized. For CMOS realization, rewritten next states enter complete-network cleanup and mapping. The objective includes the template, literal-selection muxes and demanded inversions; registered controls must remain stable during the assigned evaluation phase. Extending the control network upstream requires a separate timing and phase-legality check.

7Technology Mapping and Trials

CMOS expansion is followed by mapping only. Proposed DOMINO boundaries impose no barriers on static mapping; bounded shared scalar cones may instead receive separate partitions to preserve their fanout sharing. The provider uses the shared handoff [S §3.4, §5] and physical budget, sizing and boundary environment of [A §4–6]. Its responsibility is cell covering and physical refinement of the selected native network.

There are two selection levels. Section 5 selects a consistent topology using native proxies; mapping trials then compare complete native profiles using the cost of their covered networks. An incumbent profile competes with a variant that adds P1 and multi-representation exploration. Both start from the same source, receive fixed bounded work shares, and retain separate candidate artifacts. A publication reserve ensures that selecting a profile yields one complete netlist and its matching source-state correspondence.

Algorithm 3 Select across mapped native profiles
  1. synthesize, validate, expand and map the requested profile; retain its complete artifacts and netlist
  2. if enabled and admissible, repeat from the same source with P1 and multi-representation choices
  3. measure hierarchy-weighted combinational gate count, then cell area, then maximum region delay
  4. choose the lexicographically better mapped result; ties or an unavailable/refused alternative keep the incumbent
  5. publish the winner's logical selection, correspondence and mapped output together

Native proxies can rank structures differently from cell covering because the library exposes different cuts, polarities and sharing opportunities. Profile selection therefore uses hierarchy-weighted combinational gate count, with cell area and maximum region delay as tie-breakers. This region-delay objective is distinct from complete sequential timing; it does not characterize the physical timing of a DOMINO implementation.

8Budgets, Reuse and Determinism

Structural work (preparation, identity realization, validation and publication) and optional search use separate deterministic ledgers. Search exhaustion preserves a complete legal incumbent; structural or process-resource refusal produces no output. Failure to find an endpoint candidate within a finite search allowance does not establish infeasibility.

Library-independent ranking permits logical selection reuse independently of the mapping library. Library-aware ranking instead includes library contents, cost-model version and relevant timing assumptions in the native identity. Reuse also preserves budget-dependent decisions: a search independent of its exact initial credits can replay at or above its recorded floor, while a credit-bound search requires the original credits. Hits replay recorded charges so subsequent regions receive the same allowance. Mapping reuse follows [S §3.5].

Correctness obligations. Native replacement requires exact function and composition checks on the admitted basis. Freezing additionally checks cell legality, rail demand, phase order, clock domains and original next-state functions. Reconstruction preserves those invariants across hierarchy and native barriers, enabling an independent whole-design equivalence check.

9Positioning Relative to Prior Work

Output-phase assignment [2] and DOMINO technology mapping [3] address polarity and covering; unate decomposition [12] and its application to dynamic CMOS [13] already establish that binate functions can be realized through unate blocks. Our distinction is the mandatory register-rooted endpoint objective, with mixed static/DOMINO cost and preserved source state. Exact unate covers and decomposition supply established foundations for this objective.

Priority cuts [14] bound structural boundary exploration. Here a retained boundary is judged by constrained functional realization and surviving shared logic, rather than support size alone. Care-aware decomposition has also been studied for LUT mapping [17]; the endpoint search applies divisor-image completions to static and first-phase interfaces under DOMINO legality and rail cost.

AnySyn [15] motivates evaluating transformations with the target cost rather than graph size. Multiple-node Boolean optimization [16] demonstrates the value of coordinated changes to shared logic. Our specialization couples these ideas to sequential endpoints: outside consumers protect live cones, interface alternatives are priced jointly, and common divisors must respect the endpoint clock domain and phase order. Residual rewriting [5, 6] and structural choices [8] remain conventional machinery. The proposed combination, and the literal-selection opportunity of Section 6, are the focus of the method.
