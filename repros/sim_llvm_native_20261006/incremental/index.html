Stable simulation partitions and build footprint

2026-10-07. Measured production improvements; the full native runtime migration remains incomplete.

Partition policy

Cold builds retain large pressure-limited colors. Incremental discovery reads the preceding successful plan's terminal anchors, rechecking dependency, phase, control and live-word limits. An edited interval can split locally without shifting every later budget cut. Tuning changes invalidate incompatible anchor hints.

The 32-chain regression adds one arithmetic operation and exposes its old result. Original global repacking preserves none of four unaffected partitions. Saved endpoints preserve all four. This does not guarantee one or two objects for arbitrary edits: repeated occurrences, deleted anchors, width/interface changes, or changed control boundaries may need more.

Research applied

RepCut (ASPLOS 2023) forms sink-cone clusters, treats current-state values as sources, and balances computation with replication/cross-partition cost. gsim's partition implementation coarsens first and uses dynamic programming to minimize cuts under a partition-size bound. Neither supplies LiveHD's requirement to retain compilation boundaries across source revisions. Saved anchors are an additional reuse constraint, not an implementation of either paper.

Native reuse

Stable color identities replace dense schedule numbers in object filenames/symbols. A per-object sidecar hashes complete unoptimized IR and emitter/toolchain salt and verifies object bytes; matching objects skip LLVM optimization and instruction selection. Corrupted/missing pairs regenerate. The single lhd.incremental switch controls generation reuse, cut hints and object lookups.

Execution and remaining gaps

Dino’s paired five-million-cycle execution is about 1.17 s Slop and 2.04–2.10 s LLVM (previous LLVM 2.21 s). Minion’s 100,000 cycles are roughly 2.0 s Slop and 2.5 s LLVM. Byte-identical LLVM executables ranged from 2.47 to 2.61 s across paired runs, so small differences are not treated as improvements or regressions. Program assertions pass and output digests agree across backends. These program tests do not exercise the intentionally faulty edit used for the incremental experiment.

Hardware perf sampling is disabled by the host. GDB’s interrupt samples put 56% of Dino samples in its main native kernel, 23% in the first C++ color adapter shard, and 13% in memcmp called by that shard. This is diagnostic sampling, not an unbiased hardware profile. Sample counts.
