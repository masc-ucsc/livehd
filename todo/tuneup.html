Tune-up per HighTide benchmark (asap7, pre-CTS)

Per-benchmark LiveHD options and results against the HighTide OpenROAD flow, pre-CTS, measured with one common scorer. Provenance: each row is the best stored run for that benchmark. The runs come from several intermediate LiveHD builds (the bring-up and improvement branches, before they were merged), so a row's option list can name options that exist on master only since commit aedc974e3; the benchmark runs have not yet been repeated on a single build. Treat the numbers as the best demonstrated result per design, not as a reproducible regression baseline. Designs marked violated have not been tuned to closure: most of the remaining gap is wire RC on macro-spread nets and placement-blind buffer chains, and HPWL is still roughly 2-3x the OpenROAD reference where compared. The OpenROAD reference itself violates setup on coralnpu, cnn, eyeriss, vortex and NVDLA/partition_c, and its ternip netlist is degenerate (a missing SRAM wrapper leaves most state undriven), so the ternip cell comparison is not meaningful.

Method

  • Flow: RTL → lhd synth (mapping + native DREAMPlace) → one OpenSTA scorer (placement RC, ideal clocks, the OpenROAD flow's own SDC and Liberty set). The reference is the HighTide OpenROAD flow's 3_place.odb scored by the same script, so both columns are directly comparable. Pre-CTS only; setup only.
  • Objective per benchmark, lowest wins: penalty = max(0,-WNS)/s_w + max(0,-TNS)/s_t with s = max(reference negative slack, 5% of the clock period); penalty is 0 exactly when setup timing is met. Then fewest logic cells (no fill/tap/endcap). WNS/TNS are in ps; HPWL in metres; cells exclude physical-only instances.
  • Every row is the best stored run of the selected LiveHD binary for that benchmark; the tag names the run directory under HighTide/artifacts/lhdsweep/runs/. Each tune-up parameter list is the complete set of non-base options of that run. Base settings applied to every run: merged asap7 RVT FF Liberty with the platform dont_use list, benchmark utilization and density, synth.memory=flops, pass.abc.drop_init=true, pass.abc.derived_clock=true, synth.place.unknown_const=zero.
  • Run times are wall minutes on a shared, heavily loaded machine (single placer thread unless noted); use them for order of magnitude only.

6 of 20 benchmarks meet setup timing; 5 of them with no more cells than OpenROAD.
