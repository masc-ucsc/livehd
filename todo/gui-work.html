gui-work Agent socket and floorplanning: adversarial test, fixes, wanted features

In progress (opened 2026-11-15) An agent drove lhd synth --gui through its Unix-domain agent socket (tools/lhd_gui.py) on HighTide designs (liteeth, 5 macros and 17k cells, first), to improve floorplans and macro placement. It attacked the socket with malformed, hostile and out-of-range requests, fixed what broke, and wrote down what an agent still lacks. Sources: pass/place/gui/, 2i-interact (the GUI), 2p-placereason (the explore tiers).

Drafting: this page is being filled while the work runs. Sections below are final only where they carry a measurement.

Done

  • G1 find / highlight / select regex could freeze the whole GUI. A nested quantifier ((.*)*x) ran in std::regex (backtracking) under the session lock: the agent socket, the token-protected page port and the flow all stopped, lhd spun at 100% CPU, and only a kill recovered it. Now RE2 (linear time, compiled before the lock): the same request answers in 48 ms. Backreferences and lookaround are refused with a message.
  • G2 restart with a set flag that does not exist (or is read-only, or cannot hold the value) was answered ok and queued; the re-executed lhd then exited with status 2 and the session was gone with its pins and edits. The flag name, read-only bit, boolean and integer values are checked against the options table before anything is queued.
  • G3 restart with a checkpoint that does not exist (99, a string, -5) restarted from the beginning, dropping every edit. Out-of-range is now a refusal / note; absent or -1 still means the start.
  • G4 find limit and critical n silently ignored a string or a fraction and clamped 0 or a negative number to 1. They are bounded integers now and say what is wrong.
  • G5 A "state\u0000x" command ran as state (C-string truncation). Strings keep their length now.
  • G6 move rejected scalar x/y with an unhelpful message although the help text shows them; one number now applies to every node. A relative or aligned move of a placed macro says it is fixed and to use absolute x/y.
  • G7 describe did not accept #index (which move, select and highlight_names do).
  • G8 A whatif candidate without "cmd" failed with "bad command json"; it is a move now and a bad candidate is named by its position.
  • G9 The screenshot page command did nothing visible: a missing file name or work directory was silent. It now sets the note with the path it wrote (under <workdir>/synth/place/gui, basename only).
  • G10 Screenshots were stored (uncompressed) PNGs: 2.4 MB for 900x900. zlib level 3 now.
  • G11 Dead sessions left their /tmp/lhd-gui-<pid>.sock: 1,089 had piled up. A new session removes the sockets of processes that no longer exist (same user, lstat socket, kill(pid,0) says ESRCH).
  • G12 valid_color ran a std::regex on caller text; it is a plain character check now.
  • F1 New macro_scan {node, grid | positions, orientations?, top?}: ranks legal positions (and mirrored orientations) of one macro by pin-to-logic wirelength in milliseconds; a first screen before whatif and explore.
  • F2 evaluate wait_ms=N returns the measured summary; before, evaluate answered "processed" at once and the numbers appeared later in state.evaluation_seq.
  • F3 tools/lhd_gui.py: screenshot out=FILE (PNG over the socket), wait state=gate, macros, --retry SECONDS (the socket is down while a restart re-executes lhd).
