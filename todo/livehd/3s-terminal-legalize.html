Implementation

  1. Rank timed data nets by minimum pin slack, excluding clocks, resets and supplies. Select up to 10% globally. Eligible two-terminal nets share a horizontal or vertical bin strip. Solve their placements jointly in one SAT instance, sharing one placement decision for each physical cell. Endpoints stay in their original center bins and within configured displacement radii. Overlapping candidate placements are mutually exclusive across all selected nets. Row/site legality, pin-access witnesses, competing corridors and aggregate bin occupancy must all pass before commit. The step-1 occupancy budget is the GP target density, leaving room below the hard cap. If a selection conflicts, drop the least critical pair in the conflict core and re-solve the remaining set jointly. Then minimize maximum displacement over the retained candidate menus. An optional joint_minimize_total objective additionally minimizes total displacement while preserving the selected edges and maximum-displacement bound. No endpoint is locked before the joint solution. Multi-terminal nets await explicit RSMT-edge evidence.
  2. Place the remaining selected critical cells near their GP positions and lock all accepted critical cells for the remainder of this transaction. Critical padding is independently tunable (default zero), so noncritical whitespace need not displace an otherwise legal critical cell.
  3. Try remaining same-bin connected pairs in timing order. Their occupancy allowance is local_pair_fraction * target_density, initially half the GP target, including cells already installed. Accepted pairs stay locked. Later cells cannot obstruct an accepted corridor.
  4. Search directly for available destinations, with no maximum bin distance. Reserve critical cells first, then place the remaining cells in timing order, so less critical cells absorb most of the displacement. Neighboring bins are searched when they can offer a closer physical site. This avoids repeated pushes and oscillation. If timing order fragments rows, restore only the unprotected remainder and retry widest-first. If nearest positions still split free space into unusable fragments, a final widest-first retry packs the padded footprints against gap/bin edges. Mandatory side spacing, critical locks and local-pair locks remain unchanged.
  5. Reserve left/right sites around remaining cells (initially one each side), and enforce a hard per-bin area cap (initially 80%). Macro bodies and rounded placement halos reduce actual usable row capacity; fixed standard cells consume capacity. Cells crossing bins contribute fractional area to every touched bin. An independent native legality check precedes output.

The mode replaces ordinary final detailed placement, tie relocation and post-GP optimization. It defaults to synth.place.legalize.terminal=true. The user approved RSMT routing feedback, 5 µm macro halos, 256 critical-pair proposals, no local-pair proposals, total-displacement minimization, remainder wire weight 4, and SAT budgets of 1000 ms / 10000000 conflicts. Timing protection uses a fresh callback at the final GP checkpoint when available; geometric-only flows have no timed nets to select. GP-only mode does not legalize. The terminal grid inherits the native routing auxiliary grid, bounded for small cores by physical row height and widest-cell area under the hard cap. Explicit replay grids are preserved.

What is guaranteed, and what is measured

The hard cap is never silently relaxed. Accepted locks never move in subsequent legalization steps. Failure leaves the input floorplan unchanged. Total area below the global cap is necessary, but row fragmentation, fixed geometry, padding and discrete cell sizes can still make a particular lock set or search fail. Exhausting candidate choices is a search failure, not a proof of infeasibility. Movable cells currently require a compatible single-height row/site.

Locking cells does not prove WNS non-regression: alignment and initial legalization can move critical cells, and displacement on other nets can affect timing. Compare fresh WNS/TNS and actual CTS/routing results. A straight pin-access witness is a geometric alignment constraint, not a committed wire or a detailed-route certificate. The joint stage conservatively accepts only two-terminal nets using bin-strip geometry and physical pin-access checks. It does not yet consume exported FLUTE tree edges.
