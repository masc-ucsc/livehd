2c-cleanup Codebase deduplication & drift cleanup

Codebase-wide review (2026-11-22, ~1,053 non-test C++ sources across core/, graph/, lnast/, inou/, upass/, lhd/, lsp/, pass/, and tools/) targeting near-duplicate code sections that share similar structure but have diverged in behavior. Several drifted copies already contain active soundness, miscompile, use-after-free, concurrency, or data-loss bugs. The review below records the changes and the proposals retained from the original audit.

Depends on

None. Subtasks A–F are independent by subsystem and can land incrementally; items marked [Bug] are active defects worth fixing first. File persistence and JSON consolidation in Subtask F complements json-metadata, and SDC/timing unification in Subtask D complements 2q-fasttimer.

The staging e-graph now treats a single unknown bit as typeless. Slang and the writer share the keyword table, and Pyrope canonicalizes quoted generic declarations to the identifier used by the body. STEP is a case-sensitive Pyrope name. The writer can still quote it, and Slang keeps it as a generic. True reserved spellings such as pipe retain their established folding behavior. The runner uses an indexed, template-aware registry, while lowering filters a vector of extracted functions and specializations. A shared resolver needs to express both candidate policies and preserve the runner’s exact-match fast path. Kept import aliasing and SSA demotion under their existing lexical context. Other helper consolidation stays local in this pass, including LLVM object emission, which has separate DUT and testbench output contracts.
D — Synthesis and timing Shared synthesis tuning proof and persistence, hardened the USYN pre-map allow-list, used port IDs for sparse Hotmux arms, and added latch handling. Aligned timing what-if RC validation, frozen-name lookup, endpoint hold slack and report units. Reused Liberty truth, unit, latch-clock, quoted-string scanning and interpolation helpers. The cell scanner also accepts semicolonless scalar attributes. Kept existing backend defaults and restricted USYN’s accepted command set to the GIA operations it drives. The alleged endpoint budget off-by-one checks the graph size after insertion against an inclusive cap. OpenTimer shares clock-pin classification between indexed and detailed feedback. A global shortest clock period cannot stand in for a pin’s clock domain, so ranking retains its existing normalization when domain timing is unavailable. OpenTimer’s script replay has its own ordered selector resolution, so consuming the fast timer’s records is a separate migration. Kept full Liberty group construction separate from the lighter cell inventory scan. Backend-specific table, clock and option precedence stays with the consumer. A full backend parity contract and endpoint formula compaction would require separate changes to those data models.
E — Placement and routing Completed boundary-anchor vectors, preserved route taper through copies and stored routes, reused rectangle coverage and RAII Steiner topology, and restricted domino rail candidates to routing layers. ECO trials now retain legal geometry, density and QoR history, and share clock/reset protection. JSON retains control characters through escaping and handles non-finite metrics. DRT-0074 was caused by the final router handoff. The intermediate region and SAT passes preserve pin status for the final legalization stage. The directional RC maximum in repair is a conservative bound and the mean in ranking is an estimate. A single reduction would alter their intended roles. Kept the warm-settle policies at the call sites where they choose which cells can move. Clock, reset, PCRS and sizing candidates have stage-specific Liberty and geometry requirements. The remaining buffer selection, electrical-chain, and GUI/probe refactors are separate from the placement and routing fixes in this pass.
F — Core and persistence Fixed the dangling view, formal portfolio selection and hierarchy null handling. The low-level LEC pass rejects trust of either top module. Shared profiling, file publication, locking, partial JSONL recovery, and Pyrope import resolution. Migrated the cache and manifest writers that publish independent files or directory generations, checked cache schema, and reused read, write, JSON and hash helpers on the affected runtime paths. The technology-mapping cache retains its generation-pointer protocol, Lean publishes companion artifacts with its pair transaction, and file export streams large inputs and preserves modes. The single-file helper cannot replace those protocols directly. Kept the formal entry points’ option precedence and diagnostics local. Some boolean knobs use EPRP truthiness while others validate fixed spellings. Remaining CSV and hash sites stay local where their separators, seeds or persisted representations differ.
