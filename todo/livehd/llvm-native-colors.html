Independent LLVM simulator objects

Implementation and validation are complete. LLVM colors now emit native PIC objects directly. Native symbol-table validation rejects every named undefined symbol, including compiler-runtime calls introduced during instruction selection. The generated host C++ links these objects normally.

Scope

Color arithmetic, memory addressing, bounds checks, forwarding, write staging, undefined memory draws, and wide division are implemented inside the object. An explicit table supplies data pointers to packed memory and staged writes. Memory entries contain contiguous words without Slop metadata. Shared C++ templates retain reset, checkpoint and support operations.

The C++ driver, state commits, scheduling, hierarchy traversal, input/output packing and change propagation remain. Unused Slop pure evaluators are omitted. This is the requested first step, not a claim that all design-specific C++ has been removed.

Validation

  • 11 LLVM code-generator unit tests pass, including independent memory objects and wide division/copies.
  • 19 simulation test blocks pass on both Slop and LLVM, plus backend switches and evaluator shards.
  • 10 additional memory tests pass with default and signed Slop carriers.
  • Checkpoint creation and bit-exact restart with VCD pass.
  • Unchanged setup preserves object timestamps; a missing object regenerates with identical bytes.

Issues caught during integration

  • The old LLVM backend omitted pre-rise memory write previews. A seeded ordering-none trace reproduced this in the frozen baseline, while Slop replayed writes correctly. The native IR now replays the read's write prefix; the dedicated seed-trace regression passes.
  • Minion has about 5,000 color objects. The resulting link command exceeded the shell argument limit. Both host build paths now use response files; final integration the dedicated seed-trace regression passes.

Measurements

Full benchmark report, plots and raw evidence

The final 18 LLVM lhdtrack cases pass every recorded checksum, as do the 18 Slop comparison cases and 36 baseline cases. The final object audit checks 5,284 native ELF objects (4,981 from Minion): zero named undefined symbols and zero unused Slop pure includes.

Whole-core Pyrope Minion, 100,000 cycles: pinned median execution is 2.681 s native LLVM, 2.831 s old LLVM and 2.273 s Slop. Native LLVM setup + compilation is 280.08 s versus 345.47 s old LLVM and 310.42 s Slop. All variants retire 41,321 instructions and finish at PC 1032. Construction times are single wall-clock samples on a shared host.

Independent native objects are not a uniform speed win: 16 of the 18 small-design LLVM measurements slow down relative to the old cross-language-inlining path. The C++/object packing and call boundary remains an optimization opportunity. See the report for individual results and measurement limits.

Follow-up: a controlled br_credit_sender experiment with identical old host/kernel bitcode reproduces the runtime regression when compiled separately (1.337 → 1.742 s; current native 1.730 s). Evidence and remaining C++ inventory. Minion still emits 75.3 MB of C++ plus 6.4 MB of headers; removing this packing/commit boundary remains future work.
