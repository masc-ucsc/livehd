2w-warpspace Density warp for FP centroids and macro anchors

Use the demonstrated density deformation to guide memories toward space that should contract or expand. During fp_plan, shift centroid targets before alignment snapping. During macro_plan, periodically refresh a virtual pull edge per movable memory; the placement optimizer performs the movement.

Prototype landed; placement integration planned The standalone C++ tool and its 32-bin smoothing default are implemented. The two placement options and hooks below are pending; this page does not claim that native placement already consumes warp directions.

Depends on

  • The existing native FP → macro → final-cell placement pipeline, described in 3p-placement, supplies geometry, centroid membership, hierarchy and stage handoff.
  • Reuse the placement-color membership and hierarchy accounting when placement colors are selected. Synthesis-color and hierarchy-only FP must also remain supported.

Design notes

Accepted density model

D[b] = standard-cell area overlapping bin b
O[b] = union area of physical macro bodies overlapping bin b
F[b] = bin_area - O[b]
B    = 32 × 32 box filter (global average when it spans the block)
smooth_rho[b] = B(D)[b] / B(F)[b]
rho_target[b] = 0.5 * D[b]/F[b] + 0.5 * smooth_rho[b]
requested_free_area[b] = D[b] / rho_target[b]
normalize requested free areas to sum(F); add O per bin
solve the smooth no-fold mesh warp; sample Δwarp at each memory center

Use the prototype's regularization and empty-bin conventions. This is a soft area target, not an exact density cap after resampling. The 32-bin filter width is distinct from grid resolution; the comparison runs used 32×32 bins, so their smoothed density is block-wide. The die boundary stays fixed, physical cell mass and reserved occupied area are conserved, and macro shapes are metadata for anchor suggestions rather than deformable physical cells.

FP handoff

snapshot = current FP density, physical macros, leaf/hierarchy centroids
field = warp(snapshot)
for each leaf centroid c:
    memories = unique owned movable memories(c)
    shift[c] = mean(field.delta[m] for m in memories), or zero
for each hierarchy node h, bottom-up:
    shift[h] = sum(shift[c] for contributing descendant leaves c) / count(c)
shift each unsnapped centroid target once using the saved original target
snap hierarchy/centroid targets using the existing snap policy
freeze targets and hand them to macro_plan

The hierarchy reduction averages centroid movements, rather than pooling all memories under the parent. A leaf with ten memories does not get ten times the parent weight of a leaf with one memory. Only contributing leaves enter the parent count; a branch with no movable memories does not dilute the average.

Macro optimization

run macro GP warmup with existing objectives
at each scheduled refresh, up to the configured budget:
    field = warp(current placement density and macro geometry)
    for each movable memory m:
        anchor[m] = current_center[m] + field.delta[m]
    replace virtual pull edges atomically; resume GP
between refreshes:
    optimize existing objectives + sum_m weight[m] * pull(center[m], anchor[m])
perform the existing macro snap/legalization and lock macros
clear virtual warp edges before final cell placement

The exact pull penalty should reuse a supported optimizer anchor term, with its weight reported separately. A refresh changes the objective endpoints, not placement coordinates. Benchmark pull strength, warmup and cadence for oscillation, wirelength and timing before proposing any enabled-by-default placement policy.
