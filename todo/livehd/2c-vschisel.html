2c-vschisel Configurable Pyrope SoCs and the Chisel comparison

Extend lhdsuite’s mixed_soc so different Rocket and BOOM configurations can coexist with Gemmini and a selectable interconnect. Measure the cost of generating Verilog from Chisel and the downstream effects of preserving loops and conditional module calls in maintained Pyrope.

Depends on

None.

Subtasks — implemented in the working trees

  • A — Pass a configuration through the tile hierarchy.

    LiveHD specializes a module on a whole compile-time record, including nested queue settings. A parent can forward the record and use its fields for port widths. Equal bindings reuse a definition and keep independent register state. On the earlier baseline a whole record was rejected as a runtime value. The record regression now exercises both repeated and unequal configurations.

    lhdsuite’s mixed_soc/scripts/check_profiles.py runs the uniform and heterogeneous 16-tile presets for 36,000 cycles. Both produce checksum 6893873800832869613. The multiplier fixture observes an early result at cycle 3 and the baseline at cycle 5. BOOM’s four-fast-slot memory queue asserts backpressure two cycles during a burst that fits in the eight-fast-slot baseline. Binding dispatch width 2 to the single-lane memory queue fails elaboration with its queue name. Other dispatch widths and other Rocket options remain porting work.

  • B — Resolve sibling imports in their own package.

    Rocket and BOOM now keep the original module filenames, including PTW.prp. Each importer binds its own sibling in compilation, incremental lookup and LEC. The two-package regression proves distinct leaf behavior against RTL, edits one leaf, and checks reuse of the other package. The old Rocket renaming script has been removed.

  • C — Preserve runtime activation for a stateful child.

    LiveHD follows the clock and reset of each domain through nested calls, including active-low resets, and diagnoses two independent reset bindings on a shared conditional clock. The multi-domain regression exercises reset while disabled. Native simulation records per-DUT kernel attempts, executions and skips when built with --set sim.eval_counts=true.

    lhdsuite’s gemmini/controller/check.py compares the load-controller DMA tracker using Chisel’s explicit gate and Pyrope’s conditional call. With the same command stream and activity scheduling, each skips 34,000 of 64,001 evaluations and maps one gate driving 26 flop bits. Median execution times were 7.74 and 7.94 ns/cycle respectively. The flat LiveHD check reached PROVEN-bounded(6). An independent two-phase PDR miter proved equivalence under the original DMA return contract and refuted a corrupted completion tag.
