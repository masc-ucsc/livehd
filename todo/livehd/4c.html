4c Checkpoint format + reload validator

Goal. Save and restore complete simulator state so repeated simulation tasks can resume near the requested cycle instead of replaying from cycle zero. Checkpoint compatibility is keyed by semdiff's canonical structural identity and an explicit format/simulator version.

Depends on

  • pass/semdiff — canonical structural identity for matching checkpoint state.

Subtasks — pending

  • A — complete checkpoint format. Store every value that affects future execution, including registers, memories, clock/edge history, and simulator scheduler state.
  • B — compatibility and reload validation. Reject incompatible checkpoints cleanly using structural identity, format version, and simulator-generator version; never partially restore state.
  • C — incremental simulation use. Let simulation/query tasks select the nearest compatible checkpoint and report the checkpoint used and cycles replayed.
