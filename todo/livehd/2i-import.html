2i-import Link multiple precompiled lg: libraries

Goal. Complete the precompiled-artifact path for fast incremental compilation: one lhd compile invocation accepts several independent lg: inputs, links them deterministically, and continues through the normal compile/emit pipeline.

Already working

Source-relative Pyrope imports, sibling-module lowering, lhd scan, mixed ln:/lg: linking, canonical graph digests, structural matching, and single-library loading are landed. They are not pending work on this page.

Pending

  1. Lift the raw-library cap. Remove the explicit rejection of multiple pure lg: inputs in lhd compile and merge each library without assuming gids are process-global.
  2. Collision-safe identity. Use semdiff::canonical_digest to form candidate buckets, then confirm equality with structural_match before deduplicating. A digest match alone must never decide hardware identity.
  3. Name policy. Deduplicate structurally identical modules; preserve distinct same-name modules under deterministic internal names; emit a bare Verilog name only when it is unambiguous.
  4. Dependency and reachability handling. Resolve Sub dependencies across all inputs, diagnose missing/ambiguous providers, and retain only modules reachable from the requested top when a top is supplied.
  5. Link report and regressions. Report loaded, deduplicated, renamed, and pruned modules. Test identical modules from independent libraries, distinct same-name modules, cross-library hierarchy, deterministic output, and a missing dependency.

Done when

A design split into independently compiled libraries links with multiple lg: inputs, produces the same result as a clean whole-design compile, and reuses unchanged artifacts after one source module changes.
