2t-timeclosure Timing closure inside global placement

Implement a single-threaded, non-ML timing loop in native DREAMPlace GP: optimize achievable period with a LiveHD timing proxy, model buffering and reserve its space early, then materialize buffers and resize cells in phase 7.

In progress — native late proxy and observation controller foundations implemented; GP integration pending The design rationale and algorithm references are in timing_closure_plan.md. This page translates that proposal into ordered deliverables, integration points, review resolutions and acceptance checks. Constants are initial experiment values, not validated settings or approval to change existing defaults.

Current evaluation scope: CNN and litepci, starting from the exact signal netlist in OpenROAD's saved preCTS database. No resynthesis is used. OpenSTA compares both placements before CTS, then matched CTS/routing establishes post-route results. LiveHD synthesis/resynthesis comparisons are deferred until this shared-netlist flow works. Earlier Eyeriss traces remain useful for replay.

First delivery: complete A–C and the observation/replay part of H. Establish trustworthy proxy timing and gate decisions before enabling forces or graph edits. The core loop must work with resynthesis disabled; K adds it independently.

Depends on

  • native placement supplies the native placement stages, mapped physical graph, technology RC, checkpoints and export. Reuse the implemented interfaces; this task does not wait for every outstanding placement experiment.
  • 3r-route supplies RSMT-RUDY and full-footprint congestion measurements. Its pending stability-based timing warm-up is implemented by H for the new loop, avoiding a second independent gate controller.
  • 2p-plan E and 3s-terminal-legalize supply legalization and timing protection for the phase-7 handoff. Existing legalizers remain usable; optional SAT alignment is not a prerequisite.
  • 2is-incsynth is needed only for K: reuse color environments, mapped-body remapping and equivalence checks. Its once-per-run policy remains the legacy policy.
  • 1f-fixes measures the legacy default loop this task replaces (HighTide asap7, 2026-10-26): 446 full OpenTimer evaluations in one minimax run (88 % of 6 387 s CPU), about six per GP checkpoint from repair_gp_buffers trial scoring; each evaluation re-attaches every net and re-fits every driver (14 s); the 45 MB Liberty is rescanned at every checkpoint; GP convergence is vetoed by timing_satisfied; the timing rounds cold-restart place(). Those numbers are the control and the legacy-callback audit that A asks for. 1f fixes the default path now, independently of this opt-in mode, and reuses the B/C/H foundations (late_timing, rc_cache/star_rc, native_timing_max_overflow, the segmented-row adapter). Behaviors 1f documents must not be inherited here: timing vetoing convergence, post-density continuation to the cap, acceptance on timing alone from an unconverged density state, per-checkpoint library rescans.
