2f-lec LEC remainder — formal phase scheduling and memory correspondence

pass/lec/lec.md remains the reference for the implemented LEC engine. The current core already has direct cvc5 encoding, inductive flop-cut and reset-based BMC, memory arrays, hierarchy-aware proof ordering and proven child collapse, semdiff skips and state pairing, formal-block consumption, case splitting, a verdict cache, solver budgets, and witness generation. This page intentionally keeps only the work that remains relevant to LEC.

Verdict discipline

PASS means definitively equivalent and FAIL means definitively different; timeout, unsupported timing, and ambiguous correspondence remain INCONCLUSIVE. Collapse, pairing, phase scheduling, and every retry must preserve that contract. An abstraction may cause more work or an UNKNOWN, never a wrong verdict.

Pending — hierarchy-aware formal phase scheduler

This replaces formal coloring and single-edge graph normalization. The scheduler is a read-only formal analysis: it does not color partitions, rewrite an LGraph, synthesize a phase counter, or thread timing state through module ports. pass.single_edge remains a landed standalone transform and an Icarus/formal oracle, but LEC and verify stop depending on it when this work lands.

Today the formal preflight normalizes the whole reachable tree before the leaves-first driver starts. It therefore refuses mixed latch/edge hierarchy, refuses the memory-bearing multi-phase path, and prevents otherwise-provable children from reaching the existing prove-then-collapse loop. The encoder's sequential boxes also expose only one transition per source period, and the memory reader does not retain RD_CLK_POLARITY. These are the remaining implementation gaps.

Schedule analysis and cone construction

Starting at the selected top, resolve clocks through actual instance bindings and assign a semantic phase to every instantiated register or latch and to every synchronous memory port. For each endpoint and phase, walk its data, enable, reset, address, write-data, and observation cones backward across non-opaque hierarchy. Stop at constants, primary inputs, state boundaries, and opaque boxes. Memoize a gate within one phase; if one gate feeds two phases, encode it in both cones.

A batch evaluates from an immutable incoming-state snapshot and commits its endpoints simultaneously. A later batch in the same source period observes the state committed by earlier batches. This ordering is formal metadata; it must not be materialized as graph state.

Single-root v1 schedule

  1. active-low clock-role latches close immediately before rise;
  2. posedge flops, posedge memory ports, and data-gated latches update simultaneously;
  3. active-high clock-role latches close immediately before fall;
  4. negedge flops and negedge memory ports update simultaneously.

A latch-close microstep shares the symbolic input snapshot of its adjacent edge. Rise and fall have distinct input snapshots, each shared between REF and IMPL. LEC compares external outputs after rise and after fall; an unclocked assertion is checked at the full-period boundary by default. Bounds and reset counts continue to mean source periods.

Clock-role and data-role latches are different. Only a latch whose controlling cone resolves to the root clock receives close-before-edge scheduling. A data-gated latch keeps Pyrope's ordinary tick semantics and joins the rise/base batch; active-low polarity changes its write condition, not its phase.

Clock_cell

A Clock_cell is timing metadata, not an SMT data value and not a scheduled state endpoint. Canonicalize a chain to its root clock, edge parity, and active-high guard. Sample the guard before the reference rise, reuse that sample for all affected rise/fall consumers in the period, and combine it with each endpoint's own enable as endpoint_enable & clock_guard. Inversion swaps the consumer edge; div != 1 remains a named refusal.

Memories

Retain read and write polarity for each synchronous port in the Memory IR, including RD_CLK_POLARITY from Yosys; keep a compatibility fallback for graphs that only carry the legacy global polarity. Schedule only the ports active in a phase. Ports in one batch keep the existing simultaneous write, forwarding, and collision policy. This fixes formal timing only; the separate Verilog-codegen work remains in 2m-multiport_mem.

Hierarchy and collapse

Replace the one-transition-per-period sequential State_box with transition and Moore-output contracts for each semantic phase. An instance resolves those phases through its own parent clock bindings and sampled clock guards. Collapse a child only after its intermediate phase contracts prove; otherwise leave it expanded. A body-less trusted black box is conservatively allowed to transition on both edges of every declared clock.

Scope and failure policy

v1 imposes a total order for one root clock. A flop-only design with unrelated roots keeps the current detected-edge encoding. If a latch, phase-sensitive memory, or phase box would require ordering unrelated roots, fail closed with the clocks and endpoint named. Fluid flops, unresolved latch clock/data classification, clock division, and unsupported asynchronous memory timing also remain explicit refusals.

The schedule signature, including endpoint phases, root/parity resolution, memory-port polarity, and sampled clock guards, belongs in the verdict-cache key. A counterexample names (source period, rise|fall). Until witness replay can drive edge-specific input snapshots, it must refuse replay explicitly instead of silently flattening them into one cycle input.

Pending — same-shape memory permutation retry

Memory state currently pairs by shape and occurrence. The landed diverged-use guard prevents a confident semdiff mismatch from being collapsed, but it cannot distinguish structurally symmetric, same-shape memories reordered between REF and IMPL. An occurrence pairing can therefore lose a valid proof; on reset-based BMC it must never be allowed to turn crossed initial arrays into a trusted refutation.

When a solver result touches an ambiguous same-shape bucket, enumerate its small set of alternative permutations as uncertain memory pairs. Reuse the state-pairing discipline: a proof under a complete candidate mapping may pass and disclose the mapping; a refutation under a candidate is not final and must be rechecked without it; timeout or unresolved ambiguity stays UNKNOWN. Cap combinatorial search and report the skipped bucket when the cap is exceeded. Include the chosen permutation in the cache key and pair hint only when the hint is complete and revalidates against the current graphs.

Acceptance

  • posedge-to-negedge and negedge-to-posedge pipelines observe the earlier phase's committed state.
  • Active-low and active-high clock-role latches close before the corresponding edge batch; a data-gated latch and same-batch flop update simultaneously.
  • A chained Clock_cell feeds both phases from one rise-sampled guard; inversion changes edge parity and division refuses.
  • A child communicates rise-to-fall state through phase-aware contracts, and collapse yields the same verdict as expansion.
  • Mixed-edge read/write memory ports preserve polarity, registered-read behavior, forwarding, and collision rules.
  • Reset lengths, source-period bounds, output comparisons, assertions, cache keys, and edge-labelled witnesses follow the new schedule.
  • The plain-posedge path and unrelated-root flop-only path retain their present verdicts and performance envelope.
  • A reordered same-shape memory pair proves through permutation retry; a real mismatch still fails only after a pair-free confirmation.
  • Re-run the focused formal tests and the lhdsuite dino/minion LEC scenarios; shrink minion's trust list only from measured proofs, without changing the suite's known-failure policy.
